# Reading this repo as a reference

This is a generated catalog of Algorant's personal Pi setup, not a ready-to-run installation.

Borrow extension patterns from `extensions/`, agent workflows from `skills/`, prompts from `prompts/`, and visual styling from `themes/`. Supporting automation lives in `scripts/`.

Machine roles, accounts, paths, provider choices and service integrations describe his environment, even where generic stand-ins are used. Adapt them to yours rather than copying them unchanged.

The scripts are his own maintenance tools and examples, not installers for other people's machines. Do not clone and run the setup as-is.
